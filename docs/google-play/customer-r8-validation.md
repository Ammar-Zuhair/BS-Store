# تحقق بناء العميل المحسّن

اكتمل البناء المحلي بتاريخ 11 أكتوبر 2026، دون استخدام البناء السحابي لـ Expo.

| البند | النتيجة |
| --- | --- |
| الحزمة | `com.bsstore.customer` |
| نسخة التطبيق / رمز الإصدار | `1.0.2` / `14` |
| Android target SDK | `36`، مقروء من manifest الحزمة النهائية |
| R8 | `8.12.14` مع الوضع الكامل والتقليص والتحسين وإخفاء أسماء الكود |
| ملف إزالة التشويش | مضمّن في AAB ومستخرج باسم `customer-app-v14-mapping.txt` |
| أصناف غُيّرت أسماؤها في mapping | 7,051 من 8,169 صنفاً مسجلاً في الملف |
| أصناف غير مستخدمة حذفها R8 | 19,370، بحسب قائمة `usage.txt` الناتجة من البناء |
| حجم DEX غير المضغوط | 7,202,248 بايت |
| المعماريات | `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64` |
| فحص bundletool | نجح |
| فحص توقيع JAR | نجح؛ استُخدمت بيانات التوقيع المحفوظة في EAS مع `--freeze-credentials` |

هذه أعداد من أدوات البناء وليست نسب التحسين التي يعرضها Google Play،
ولا تمثل قياساً لزمن بدء التشغيل أو استهلاك الذاكرة على جهاز. لم يُجرَ اختبار هاتف فعلي.

الملفات المحلية الجاهزة للتنزيل داخل `/workspace/build-artifacts/`:

- `customer-app.aab`
- `customer-app-v14-mapping.txt`
- `customer-app-v14-r8-report.json`: يتضمن بصمات SHA-256 للحزمة وملف التشويش.
- `customer-app-v14-release.zip`: حزمة تنزيل مضغوطة تجمع الملفات الثلاثة.

نجحت اختبارات استخراج mapping ورفض الملف المفقود أو غير المناسب، واختبارات
بوابات الخرائط وصحة JavaScript المضمّن فيها، وتوافق OTA، والعروض.
نجح فحص TypeScript باستخدام `--ignoreDeprecations 6.0` لتجاوز تحذير `baseUrl`
الموجود في إعداد TypeScript الحالي. أكّد فحص Android autolinking إزالة
`react-native-maps` وبقاء `react-native-webview` المستخدم في شاشة الموقع.

فحص Expo Doctor أظهر تحذيرات موجودة خارج إعداد R8: ست حزم ذات إصدارات patch
أقدم من الموصى بها، وتحذيراً عن تجاهل مصدر الوحدة المحلية لأن نسخة البناء
تقع تحت مجلد `.tools` المتجاهل. مصدر الوحدة في المستودع الأصلي متتبع، وأُدرج
ونجح تجميعه في الحزمة. اجتاز بناء Release وفحوص Android النهائية بنجاح.

ارفع AAB الجديد إلى مسار اختبار، واختبر التشغيل وتسجيل الدخول والخرائط والإشعارات
والإيصالات والطلبات وحذف الحساب قبل طرحه للعامة. ملف التشويش خاص بالإصدار 14،
ولا يصلح للإصدار 12. تشغيل GitHub Actions مجدداً ينتج رمز إصدار جديداً وملف mapping
مطابقاً له تلقائياً.
