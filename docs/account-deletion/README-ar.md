# صفحات Google Play

هذا المجلد هو موقع حذف حساب مستقل، ومجلد `../privacy-policy` يحتوي صفحة خصوصية HTML كاملة دون اعتماد على خدمة خارجية أو JavaScript لقراءتها.

## GitHub Pages

الروابط الرسمية المنشورة:

- سياسة الخصوصية: `https://ammar-zuhair.github.io/BS-Store-Policy/`
- حذف الحساب: `https://ammar-zuhair.github.io/BS-Store-Delete/`

ضع الرابطين في Play Console. التطبيق وروابط الصفحات يستخدمان هذين العنوانين. لنشر النسخة المصدرية هنا في المستودعين المنفصلين، انسخ محتويات `docs/privacy-policy/` إلى مستودع `BS-Store-Policy`، ومحتويات `docs/account-deletion/` إلى مستودع `BS-Store-Delete` بما فيها `config.js` و`app.js` و`style.css`، ثم فعّل Pages من المجلد الذي يحتوي `index.html`. لا تنشر ملفات إعدادات الخادم أو أسراره.

## اتصال الخادم

`config.js` يحدد عنوان API العام الحالي نفسه المستخدم في تطبيق العميل. يجب أن يظل الخادم متاحاً عبر HTTPS، ويفضل نقله إلى نطاق دائم قبل إطلاق المتجر. عند تغيير عنوان الخادم عدّل هذا الملف وإعدادات التطبيقات.

الصفحة ترسل `POST /api/account/delete-with-password` مع JSON يحوي `phone` و`password`. لا تنشئ حساباً ولا تستخدم localStorage أو cookies، ولا تحفظ كلمة المرور. يحتاج الخادم إلى قبول CORS لعنوان الصفحة؛ إعداد الخادم الحالي يسمح بطلبات هذه الصفحة، بما فيها preflight. المسار محدود إلى خمس محاولات لكل IP خلال 15 دقيقة.

التطبيق يستخدم `POST /api/account/delete` بجلسة العميل وكلمة المرور. لا يمكن حذف حساب مدير أو موصل عبر أي من المسارين. تتوقف العملية إذا كان لدى العميل طلب غير نهائي، وتعرض الصفحة مسار الدعم. لا تختبر الحذف باستخدام حساب مستخدم فعلي إلا إن كان صاحبه يريد حذفه نهائياً.

بيانات الهوية والعناوين والإحداثيات والملاحظات والتحويل والسلة والجلسات تُزال ضمن معاملة قاعدة بيانات واحدة. تبقى سجلات المحاسبة بلا اسم/هاتف/عنوان العميل مع معرفات الربط الداخلية. لا توجد مدة حذف تلقائي لسجلات المحاسبة؛ هذه السياسة موضحة في الموقع. إزالة ملفات الإيصالات منفصلة، محفوظة كمهام قابلة لإعادة المحاولة في `AppSettings` بمفتاح `AccountFileCleanup:`، ويعالجها الخادم كل 15 ثانية. يجب متابعة المهام العالقة ومراجعة إعدادات النسخ الاحتياطي واحتفاظ الخدمات الفنية.

## قبل الإطلاق

راجع السياسة مع إدارة الخدمة: اسم الجهة المسؤولة، بريد الدعم المطلوب في Play Console (الهاتف الحالي لا يعوضه)، مزودو البيانات ومدد النسخ الاحتياطي والاحتفاظ القانوني. النص يعكس سلوك التنفيذ الحالي ولا يقرر مدة احتفاظ قانونية. حدّث التاريخ عند تعديل السياسة. بعد تفعيل Pages اختبر الرابطين من نافذة خاصة، ثم مسار الحذف بحساب اختبار مستقل.
