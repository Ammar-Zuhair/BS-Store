# Ammar Profile — عمار زهير المقطري

موقع شخصي متكامل باستخدام React وTypeScript وVite، بالعربية والإنجليزية، بوضعين فاتح وداكن. يعرض المشاريع الخمسة والخدمات والمهارات والتعليم والإنجازات، مع صفحات مستقلة للمشاريع وتواصل صادق عبر تطبيق البريد.

## التشغيل

يتطلب Node.js المتوافق مع الحزم المقفلة (Node 22.22 أو أحدث؛ اختُبر على 22.23.3).

```bash
cd /workspace/Ammar_Profile
npm ci
npm run dev
```

المنفذ الافتراضي 5173، والربط على `0.0.0.0`. لا تحتاج الخدمة إلى خادم خلفي أو قاعدة بيانات. بيانات المشاريع الأخرى وصفية فقط؛ لا يتصل الموقع بخدماتها الخاصة.

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
npm run test:e2e
npm run format
```

`build` يولّد حزمة static في `dist/` وHTML حقيقيًا للمسارات الثلاثة عشر، بالإضافة إلى 404. لا تعتمد قراءة المحتوى على JavaScript. خادم `preview` لفحص حزمة الإنتاج وليس استضافة إنتاج دائمة. الاختبارات تتوقع أن تعمل المعاينة على المنفذ 5173؛ لتجهيز Chromium: `npx playwright install chromium`.

## تشغيل المعاينة داخل Remote

```bash
ss -ltnp '( sport = :5173 )'
systemd-run --unit=ammar-profile-dev-5173 --collect --service-type=exec \
  --working-directory=/workspace/Ammar_Profile \
  --property=Restart=on-failure --property=RestartSec=2s \
  /usr/bin/npm run preview
systemctl is-active ammar-profile-dev-5173
curl -fsS http://127.0.0.1:5173/ar
journalctl -u ammar-profile-dev-5173 -n 30 --no-pager
```

تسمح المعاينة افتراضيًا بالنطاق الفرعي `.dev.remote-ammar.duckdns.org` وفق صيغة السماح الموثقة في Vite. لحصرها بالمضيف الكامل، ضع **اسم المضيف الفعلي** في `PREVIEW_HOST` داخل `.env` المحلية وأعد تشغيل الخدمة؛ لا يُعطّل فحص المضيف. الصيغة حسب المنصة `https://<project-slug>--5173.dev.remote-ammar.duckdns.org`، ولا يُستنتج project-slug من اسم المستودع أو اسم الجهاز. الخدمة الحالية transient وتحتاج إعادة إنشائها بعد إعادة تشغيل الحاوية.

## تنظيم المشروع وتعديل المحتوى

- `src/data/profile.ts`: الهوية والروابط ومسارات الصورة والسيرة.
- `src/data/projects.ts`: وصف المشاريع وتقنياتها وميزات كل مشروع وحدود التحقق باللغتين. لإضافة مشروع أضف عنصرًا يملك slug ثابتًا ونسختي `ar/en`؛ يتولى البناء توليد مساريه.
- `src/data/ui.ts`: النصوص والخدمات والتسميات والرسائل والتعليم باللغتين؛ TypeScript يراجع اكتمال شكل القاموس العربي.
- `src/pages/`: الرئيسية وصفحة المشروع وصفحة الخطأ.
- `src/components/`: الترويسة وأغلفة المشاريع وبطاقاتها والتواصل والنموذج والتذييل.
- `src/lib/contact.ts`: التحقق من الحقول وتكوين الرسالة ونقطة التكامل المستقبلية.
- `src/styles.css`: خط Tajawal المحلي، المتغيرات الدلالية للوضعين، المسافات والاستجابة والحركة.
- `scripts/prerender.mjs`: توليد HTML وبيانات SEO وقت البناء.
- `docs/CONTENT_AUDIT.md`: مصادر الحقائق وحدود فحص المشاريع.
- `docs/DESIGN.md`: قرارات الهوية وطريقة استخدام مرجع التصميم.
- `docs/VERIFICATION.md`: نتائج الفحوص الفعلية وظروفها.

لا توجد لوحة إدارة؛ تعديل الملفات يعيد توليد الموقع بصورة مباشرة.

## الصورة والسيرة والشهادات

لم تتوفر صورة شخصية أو CV ضمن ملفات البيئة التي راجعناها. لذلك يظهر مكوّن حروف الاسم، ويُخفى تنزيل السيرة بالكامل.

1. أضف صورة عمار الحقيقية المعتمدة إلى `public/images/ammar.webp`، ثم اضبط `profile.portrait` على `{ src: '/images/ammar.webp', width: العرض_الفعلي, height: الارتفاع_الفعلي }`. يُفضّل قص عمودي مناسب، دون تغيير الملامح. يمكن توسيع المكوّن إلى srcset عند إضافة مقاسات فعلية متعددة. لا تؤجل الصورة الرئيسية.
2. أضف السيرة الأصلية إلى `public/documents/ammar-cv-ar.docx` مثلًا، ثم اضبط `profile.cv` إلى `{ href: '/documents/ammar-cv-ar.docx', format: 'DOCX', language: { ar: 'العربية', en: 'Arabic' } }`. لا تستخدم امتداد PDF دون ملف PDF حقيقي ولا تصف لغة الملف بغير لغته. أعد البناء واختبر تنزيل الملف ومطابقته.
3. ملفات الشهادات غير متاحة؛ الإنجازات نصية فقط. لا توجد صور شهادات بديلة أو أختام مولدة. إنجاز HSA الجامعي منفصل عن شهادة المشاركة في مسابقة هائل سعيد.
4. الأغلفة الحالية طباعية، وليست لقطات واجهات. قبل إضافة لقطات حقيقية راجع موافقة النشر وغياب بيانات العملاء/الطلبات، ثم حسّن الصور وأضف أبعادًا وalt مترجمًا و`loading="lazy"` لما بعد الافتتاحية.

## اللغة والمظهر

الأولوية: لغة المسار `/ar` أو `/en`، ثم `ammar-language` المحفوظة، ثم **أول لغة فقط** في `navigator.languages`، ثم الإنجليزية. العربية الثانوية لا تتجاوز لغة الجهاز الأساسية. تبديل اللغة يحافظ على slug المشروع وhash القسم وquery ويحفظ التفضيل مع تحمل تعذر التخزين. `lang/dir` يضبطان على المستند. البريد والهاتف والتقنيات تستخدم bdi/direction.

المظهر يأخذ `ammar-theme` إن كان صالحًا، وإلا تفضيل النظام. سكربت صغير في الرأس يطبقه قبل أول رسم. الحركة لا تخفي المحتوى افتراضيًا، وتتوقف عند `prefers-reduced-motion`.

## البريد والتواصل

لا يوجد مزود إرسال. زر «فتح الرسالة في تطبيق البريد» يتحقق من الحقول ثم يفتح `mailto:` مرمزًا بالاسم والبريد والموضوع والرسالة. **المستخدم يُكمل الإرسال داخل تطبيقه**؛ لا توجد رسالة «تم الإرسال». خيار النسخ يعمل مع Clipboard API، ويظهر نصًا قابلًا للتحديد عند تعذر النسخ. لا يخزن الموقع رسائل الزائر ولا يرسلها لخادم.

نقطة التكامل هي `ContactTransport` في `src/lib/contact.ts`. عند إضافة مزود حقيقي لاحقًا: نفذ endpoint منفصلًا يتحقق من البيانات ويحد الإساءة، واحفظ المفتاح في الخادم وحده. غيّر آلية submit خلف الواجهة، ولا تعرض نجاح التسليم إلا وفق استجابة المزود. لا تضع مفاتيح في `VITE_*` أو ملفات public.

روابط البريد والهاتف وواتساب وGitHub وLinkedIn من البيانات المعتمدة. رسالة واتساب الأولية مترجمة ومحايدة. HSA معروض كمستودع خاص دون رابط للكود، وبقية روابط GitHub عامة وفق الفحص.

## SITE_URL وSEO والنشر الثابت لاحقًا

لا يوجد نطاق نهائي مفترض، ولم يتم تفعيل GitHub Pages أو أي استضافة خارجية. بعد اختيار نطاق فعلي:

```bash
SITE_URL=https://your-actual-domain npm run build
```

استبدل قيمة الأمر بالنطاق الحقيقي. يقبل البناء origin فقط، دون مسار أو مفاتيح أو بيانات اعتماد. عند ضبطه فقط تُولّد canonical وhreflang (`ar`, `en`, `x-default`) وOpen Graph URL و`dist/sitemap.xml`. عند غيابه تُحذف روابط النطاق وخريطة الموقع، ولا تُترك example.com أو روابط مخترعة. Person وWebSite وCreativeWork يولّدها البناء من المحتوى المؤكد، مع contributor للمشاريع الجماعية، ودون وظائف أو تقييمات مختلقة. Open Graph نصي بلا صورة أو شعار مزيف.

انقل محتويات `dist/` إلى أي استضافة static تختارها لاحقًا. يجب أن يُخدم **ملف HTML الخاص بكل مسار**، وليس إعادة كل المسارات إلى الصفحة الرئيسية الإنجليزية. مثال Nginx:

```nginx
location / {
    try_files $uri $uri/index.html =404;
}
error_page 404 /404.html;
```

بعض الاستضافات تستخدم خيار clean URLs أو directory index. اختبر `/ar` و`/ar/projects/bs-store` مباشرة وبدون JavaScript. تتضمن معاينة Vite المحلية middleware لتقديم ملفات HTML الصحيحة مع المسارات دون slash، وصفحة 404 بحالة HTTP 404. مدخل `/` يعرض HTML إنجليزيًا مع روابط اختيار لغة عند تعطيل JavaScript، ويوجه حسب التفضيلات عند تفعيله.
