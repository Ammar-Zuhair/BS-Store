# منصة BS Store للتوصيل والوساطة متعددة المتاجر (BS Store Platform)
## مبنية باستخدام React Native و TypeScript
> متوافقة تماماً مع وثيقة التصميم والمعمارية الهندسية لمشروع Stitch رقم **8230467423897289561**

---

## 📂 هيكل التطبيقات المستقلة

يتكون المشروع من 3 تطبيقات جوال منفصلة ومستقلة، لكل منها مجلد خاص وكود كامل:

### 1. تطبيق العميل (`customer-app/`)
- **المسار:** `d:\MyProjects\BS_Store\customer-app`
- **الوظائف والشاشات:**
  - **الرئيسية (`HomeScreen`):** شريط البحث، محدد عنوان التوصيل الفوري، عروض اليوم الخاطفة مع عداد زمني، كروت المتاجر والأصناف.
  - **تصفح الأقسام (`CategoryScreen`):** فرز حسب الأقسام والمتاجر مع إظهار سعر البيع النهائي وإخفاء التكلفة.
  - **سلة الشراء الموحدة (`CartScreen`):** تجميع الطلبات حسب المتاجر (`SubOrders`) وحساب رسوم التوصيل الموحدة وتطبيق كوبونات الخصم.
  - **إتمام الطلب والدفع (`CheckoutScreen`):** اختيار العنوان، الدفع عند الاستلام (COD) أو التحويل البنكي اليدوي وإرفاق إشعار السداد.
  - **التتبع المباشر للطلب (`TrackingScreen`):** مراحل التوصيل الخمس، بيانات الكابتن أحمد الماوري مع زر اتصال مباشر، ومحاكاة مسار الخريطة.
  - **المصادقة والتسجيل (`AuthScreen`):** تسجيل الدخول وإنشاء حساب مع محاكاة رمز التحقق OTP.
  - **الملف الشخصي (`ProfileScreen`):** إدارة العناوين المحفوظة، وسجل الطلبات السابقة وإعادة الطلب.

---

### 2. تطبيق المدير والعمليات (`admin-app/`)
- **المسار:** `d:\MyProjects\BS_Store\admin-app`
- **الوظائف والشاشات:**
  - **لوحة المؤشرات والعمليات (`DashboardScreen`):** 4 مؤشرات مالية حية (إجمالي المبيعات، الأرباح المقدرة، تكلفة المشتريات، عُهد الميدان النقدية)، وتنبيهات العمليات المعلقة وسجل التدقيق الفوري.
  - **إدارة الطلبات (`OrdersScreen`):** متابعة حالات الطلبات، تفاصيل الطلبات الفرعية لكل متجر، وإسناد الكباتن.
  - **مراجعة واعتماد المدفوعات (`PaymentsScreen`):** فحص إشعارات وحوالات العملاء، معاينة صورة الإيصال، والاعتماد أو الرفض مع ذكر السبب.
  - **كتالوج المنتجات والمخزون (`InventoryScreen`):** تصنيف الأصناف (مخزني In-Stock مقابل وساطة شراء خارجية)، مراقبة هوامش الربح، وتعديل كميات المخزون.
  - **إضافة صنف جديد (`AddEditProductScreen`):** نموذج تسجيل الأصناف وربطها بالمتاجر والتصنيفات وضبط أسعار البيع والتكلفة.
  - **المالية وعهد المناديب (`FinancialsScreen`):** كشف العهد النقدية بناءً على قيود دفتر الأستاذ المحاسبي، ونافذة تسوية وتصفية العهدة ورصد الفروقات.

---

### 3. تطبيق المندوب / الكابتن (`courier-app/`)
- **المسار:** `d:\MyProjects\BS_Store\courier-app`
- **الوظائف والشاشات:**
  - **لوحة مهام الكابتن (`DriverDashboardScreen`):** بطاقة المهمة النشطة العاجلة (`#10042`) بمحطات متعددة، ومفتاح حالة الاتصال (متصل / غير متصل)، وإحصائيات أداء الوردية.
  - **مسار وتفاصيل المهمة (`ActiveTaskRouteScreen`):** قائمة محطات المسار (المتجر الأول ➔ المتجر الثاني ➔ وجهة العميل)، مع زر ملاحة GPS واتصال مباشر بالعميل.
  - **توثيق مشتريات المتجر الخارجي (`PurchaseReceiptScreen`):** إدخال سعر الشراء الفعلي من الكاشير ومقارنته آلياً بسعر النظام، وتصوير الفاتورة الورقية، وقيد سند الصرف وخصمه من العهدة النقدية.
  - **المحفظة والعهدة النقدية (`DriverWalletScreen`):** حساب العهدة النقدية المستحقة (التحصيلات - المشتريات - التسويات)، وكشف الحركات التفصيلي، وإرسال طلب تصفية للإدارة.

## 🚀 كيفية التشغيل والتجربة

لتشغيل أي تطبيق من التطبيقات الثلاثة:

1. الدخول إلى مجلد التطبيق المطلوب، مثل تطبيق العميل:
   ```bash
   cd customer-app
   # أو
   cd admin-app
   # أو
   cd courier-app
   ```

2. تثبيت الحزم (إذا لزم الأمر):
   ```bash
   npm install
   ```

3. تشغيل خادم التطوير:
   ```bash
   npx expo start
   ```
   أو تشغيل وضع الويب للمعاينة الفورية بالمتصفح:
   ```bash
   npx expo start --web
   ```

---

### 4. تشغيل خادم الـ Backend مع إعادة التشغيل التلقائي عند أي تعديل في الملفات:
- تشغيل الملف الجاهز مباشرة من المجلد الرئيسي:
  ```cmd
  start-backend.bat
  ```
- أو عبر PowerShell:
  ```powershell
  .\start-backend.bat
  ```
- أو باستخدام أمر .NET المباشر:
  ```bash
  dotnet watch --project backend/src/BSStore.API/BSStore.API.csproj --no-hot-reload
  ```
